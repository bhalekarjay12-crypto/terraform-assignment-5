
# Assignment 5 - Terraform Fundamentals

## Introduction
This project demonstrates Infrastructure as Code
using Terraform and Amazon Web Services (AWS).

## Tools Used
- Terraform
- AWS
- AWS CLI
- Ubuntu WSL
- Git and GitHub

## Tutorials Completed

1. What is Infrastructure as Code with Terraform?
2. Install Terraform
3. Build Infrastructure (AWS)
4. Change Infrastructure
5. Destroy Infrastructure
6. Define Input Variables
7. Query Data with Outputs
8. Store Remote State (S3 Backend)
9. Create a Terraform Module
10. Use Modules from the Registry
11. Manage Terraform Versions and Providers

## Key Learnings

- Learned Infrastructure as Code concepts.
- Installed and configured Terraform.
- Created AWS infrastructure using EC2.
- Updated infrastructure using Terraform.
- Destroyed AWS resources.
- Used input variables and output values.
- Configured remote state using AWS S3.
- Learned Terraform modules.
- Learned provider and version management.
